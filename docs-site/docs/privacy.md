# Privacy Notice

Effective 2026-08-19. This notice is informational and is not legal advice.

Metrum AI is the controller for this hosted documentation site. Privacy
questions and data-subject requests can be sent to
[contact@metrum.ai](mailto:contact@metrum.ai).

## Optional support chat

The sitewide support chat uses a third-party processor. Its widget bundle,
custom element, and widget network connections load only
after you select **Allow support chat**. Before that choice, the site may read
the single first-party `metrum_docs_convai_consent` preference to restore a
prior choice, but it does not create that preference.

You can select **Withdraw support chat** in the same sitewide privacy control
used to grant consent. Withdrawal immediately removes the widget and prevents
the page from loading it again unless you grant consent later.

Widget and session data are processed by that provider under its processor terms.
This processing may involve the United States. Contact Metrum for the current
executed DPA and Standard Contractual Clauses status. Executed DPA/SCC copies
are available through [contact@metrum.ai](mailto:contact@metrum.ai) before a
managed-instance deal closes; this notice does not claim that unsigned terms
have been executed.

## Router records are separate

The optional docs widget is separate from a deployed router's usage database.
Router usage-database retention is configured under `server.retention`.
Governed content capture is disabled by default and, when enabled, has
additional encryption, authorization, and retention controls.

See the [DPA Overview](/docs/dpa), [Subprocessor List](/docs/subprocessors),
and [Transfer Schedule](/docs/transfer-schedule).
